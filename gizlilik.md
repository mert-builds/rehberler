# Gizlilik politikası: MertBuilds Yorum Botu

*Son güncelleme: 11 Kasım 2026*

MertBuilds Yorum Botu, **Mert Builds** YouTube kanalının ([@realmertbuilds](https://www.youtube.com/@realmertbuilds)) kendi videolarına yazılan yorumlara otomatik cevap veren küçük bir araçtır. Sadece kanal sahibi tarafından, kanal sahibinin hesabıyla kullanılır.

## Ne yapar

- Kanalın videolarına yazılan herkese açık yorumları YouTube Data API ile okur.
- Yorumda bir rehber anahtar kelimesi (ör. ANALİZ, KURGU) varsa, o yoruma ilgili ücretsiz rehberin linkiyle herkese açık bir cevap yazar.

## Hangi verileri kullanır

- Sadece yorumun metni, yorum kimliği ve video kimliği; bunlar YouTube'da zaten herkese açıktır.
- Hangi yorumlara cevap verildiğini tekrar cevap vermemek için yalnızca yorum kimliği olarak kanal sahibinin bilgisayarında saklar.
- Kişisel veri toplamaz, satmaz, üçüncü kişilerle paylaşmaz, reklam için kullanmaz.

## Google kullanıcı verileri

Uygulamanın Google kullanıcı verilerini kullanımı ve başka uygulamalara aktarımı, sınırlı kullanım şartları dahil olmak üzere [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy) kurallarına uyar.

## İletişim

Sorular için Instagram: [@mert.builds](https://www.instagram.com/mert.builds/)

---

*English summary:* MertBuilds Yorum Botu is a private tool used only by the owner of the Mert Builds YouTube channel. It reads public comments on the channel's own videos and replies with a link to a free guide when a comment contains a guide keyword. It stores only the IDs of comments it has answered, on the owner's computer, and collects, sells or shares no personal data. Its use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
